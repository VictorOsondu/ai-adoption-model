# Changelog

All notable changes to the model are recorded here. This project follows [Semantic Versioning](https://semver.org/): a change to the stages themselves is a major version; new supporting material is a minor version; fixes are patches.

## [1.0.0] — 2026-07-24

### Added
- Canonical spec of the six-stage model: Nomad, Observer, Dabbler, Integrator, Architect, Innovator.
- Stage locator self-assessment.
- Citation file (CC BY 4.0) so the model can be referenced and adapted with attribution.

### Notes
- The Architect stage (between Integrator and Innovator) is the model's distinguishing contribution — the self-permission gap that standard maturity models don't name.
