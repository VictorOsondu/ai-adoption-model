# Security Policy

This repository contains public guidance and framework material. Please do not include private, confidential, client, customer, student, ministry, organisational, personal, financial, legal, health, credential, or proprietary information in public issues, discussions, pull requests, examples, screenshots, or case studies.

## Reporting Sensitive Issues

If a contribution would require sharing sensitive context, redact it or use a synthetic example. If you believe sensitive material has been published in this repository, contact the maintainer through AI Tutorium rather than repeating the material in a public issue.

## Public Contribution Rule

Use public or synthetic examples by default. Named case studies should be included only when the organisation, person, or client context is already public and permission is clear.
